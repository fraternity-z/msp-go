## 维护规则

1. 新的未完成工作只写入 [TODO.md](TODO.md)，其他文档通过链接引用，不维护第二份路线图。
2. 当前架构、开发或部署行为变化时，更新 `technical/` 下对应文档。
3. 已完成且只具备追溯价值的方案、审计和报告移入 `archive/`，并在归档索引登记。
4. 长期有效的规则只保留在当前文档中；阶段流水、临时验证明细和已关闭风险不建立重复跟踪文档。
